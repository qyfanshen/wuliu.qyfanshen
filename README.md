# 华运物流集团 - 智慧物流管理平台 v3.0

## 项目简介

华运物流集团智慧物流管理平台是一套面向大型物流企业（500人以上）的双端管理系统，涵盖零担、整车、仓储配送、冷链、跨境物流等多种业务类型。

## 系统架构

### 双端设计

| 端口 | 文件 | 使用角色 | 核心功能 |
|------|------|----------|----------|
| 企业门户 | `index.html` | 访客 | 品牌展示、双端入口 |
| 管理端 | `console.html` | 企业管理层 | 数据决策、运营监控、财务结算、绩效考核 |
| 员工端 | `employee.html` | 一线员工 | 运单录入、车辆调度、异常上报、工资查询 |

## 功能模块

### 管理端功能

#### 1. 运营中心
- **数据概览** - 实时监控在途车辆、今日运单、营收数据、异常告警
- **车辆管理** - 车辆档案、状态监控、GPS跟踪、保养提醒
- **司机管理** - 司机档案、驾驶证管理、从业资格证、安全评分
- **订单管理** - 订单列表、状态跟踪、异常处理

#### 2. 财务中心
- **运费结算** - 结算单管理、批量结算、油费抵扣
- **客户管理** - 客户档案、信用额度、应收账款
- **绩效考核** - 司机排行、综合评分、准时率统计

#### 3. 风控中心
- **风控管理** - 风险预警、违章处理、安全事故追踪
- **实时监控** - 车辆位置、轨迹回放（需接入地图API）

### 员工端功能

#### 1. 日常业务
- **运单录入** - 新建运单、客户选择、线路规划
- **车辆调度** - 待调度订单、空闲车辆、快速指派
- **运单跟踪** - 实时查询、位置跟踪

#### 2. 协作与反馈
- **异常上报** - 车辆故障、货物损坏、延误上报
- **公告通知** - 公司公告、安全通知、福利政策

#### 3. 个人服务
- **工资查询** - 提成明细、绩效评分、导出报表
- **个人中心** - 个人信息、绩效统计

## 技术栈

- **前端**: HTML5 + CSS3 + 原生 JavaScript
- **图标**: Font Awesome 6.4.0 (CDN)
- **图表**: SVG 手写图表（折线图、饼图、柱状图、漏斗图）
- **后端**: Flask API 演示 (`api_demo.py`)
- **跨域**: Flask-CORS

## 使用说明

### 1. 启动后端 API（可选）

```bash
cd 物流
python api_demo.py
```

后端将运行在 `http://localhost:5000`，提供 10 个演示接口。

### 2. 直接访问

双击 `index.html` 打开企业门户，选择进入管理端或员工端。

## 业务场景覆盖

本系统支持以下物流业务类型：

1. **零担运输** - 小批量、多批次货物运输
2. **整车运输** - 大批量、专线直达运输
3. **仓储配送** - 仓储管理 + 末端配送
4. **冷链物流** - 温控运输、生鲜配送
5. **跨境物流** - 国际货运、报关清关

## 数据说明

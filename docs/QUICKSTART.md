# Quick Start

## 5 分钟跑起来

### 1. 克隆

```bash
git clone https://gitee.com/qyfanshen/wuliu.qyfanshen.git
cd wuliu.qyfanshen.com
```

### 2. 环境准备

- Python ≥ 3.10（仅 wuliu Flask 演示需要）

### 3. 启动

```bash
python -m http.server 8080
# → http://localhost:8080
```

### 4. 下一步

- 阅读 [`ARCHITECTURE.md`](ARCHITECTURE.md) 了解系统设计
- 阅读 [`DEPLOYMENT.md`](DEPLOYMENT.md) 部署到生产环境
- 阅读 [`API.md`](API.md) 查看接口文档
